交付

  • 純標誌 SVG：256 × 256，透明背景，四條路徑構成三個折面與折角。
  • 含文字 SVG：718 × 256，Hanken Grotesk 600 字標經 HarfBuzz 字距處理後轉為向量輪廓，無外部字型依賴。
  • 幾何構成 SVG：同一母版的網格、折線、圓角參考與中央間距。

scripts/generate-brand-assets.py 保存母版與輸出流程，透過 uv run scripts/generate-brand-assets.py 可重新產生三個檔案。字型授權附於 site/assets/brand/Hanken-Grotesk-OFL.txt。

網站整合

site/index.html#brand 新增標誌、字標、幾何構成、小尺寸與單色展示，以及兩版 Logo 與幾何 SVG 的下載連結。導覽列、頁尾與 favicon 採新標誌；其他產品內容與下載功能保留。

網站強調色同步為鈷藍，次色為海玻璃綠。SVG 的主色、次色、中性色、字標與構成線共用 CSS 主題變數，沿用既有深淺色控制；新增內容包含中英文文案與輔助標籤。網站使用原生 HTML/CSS，新增部分是品牌圖稿展示，未引入通用 UI primitive 或新的 UI 框架。

網站透過同源 SVG use 嵌入圖稿，以繼承主題色。獨立下載的檔案採參考配色與深色字標作為穩定預設；嵌入其他 App 時，可將 --logo-* 變數對應至該 App 的主題。完整方式見 資產使用說明。

  • bun run build 通過，包含 TypeScript 與 Vite；仍有既有 bundle 大小及 remotePreviewUrl 匯入提示。
  • AppShell、設定、啟動畫面與網站的 6 個相關測試檔，46 項測試通過。
  • 修改的 React 檔案 ESLint 無錯誤；AppShell 與 SettingsDialog 各有一個原有 effect 設定 state 的警告。
