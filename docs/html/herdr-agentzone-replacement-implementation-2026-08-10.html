Selected binary 是唯一版本權威

重要勘誤：本機 /Users/yuuzu/.local/bin/herdr 顯示 0.8.0，但其 bundled schema 是 protocol 19；研究使用的較新 Herdr source checkout/schema 是 protocol 20。實作不再把 source protocol 硬編碼到產品。

Rust service 每次以實際選定 binary 的：

  • herdr status --json
  • herdr api schema --json

建立 capabilities，並檢查 server compatibility 與 schema method presence。若缺少 session.snapshot 或 tab.create，UI 會誠實停用能力並顯示原因，不會假裝可用；也不會自動停止不相容 server。
