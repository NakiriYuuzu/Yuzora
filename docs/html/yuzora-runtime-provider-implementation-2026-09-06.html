本輪實機問題與修正

  1. 主機短暫忙碌被判成斷線：Oracle UI 曾出現 host-call-limit，但來源 helper 的 layout.export 成功。SSH HERDR 呼叫改為最多 8 個執行中、32 個總在途，等待最多 15 秒；開始與交付前重新驗證 generation。忙碌的 heartbeat／inventory 保留最後有效狀態。
  2. Terminal connector 在 topology refresh 中被重建：保留已掛載的 fallback／BSP terminal，避免更新時先清掉畫面而觸發 control takeover。已加入可重現的回歸測試。
  3. 信任失敗訊息被對話框隱藏：grant 成功前維持 dialog，等待中阻止重複確認；回應失敗只查狀態，不重送 grant。未成功時保留錯誤與新 challenge，過期回應不干擾新工作區。授權後重新偵測 Git 與重啟工作區 LSP。
  4. App 退出時 SSH stream Drop panic：russh 的 channel Drop 需要 Tokio context；HostConnection 保存 executor handle，讓原生 UI thread 釋放 stream 時進入原 context。已加入原生執行緒釋放測試。
  5. 文件與 Session 隔離：接受遠端內容時一起更新 revision；Terminal／Inspector／context menu 使用 host-scoped Session lookup，binary 診斷依主機隔離。
