實作內容

項目行為與邊界
頁籤快捷鍵提供可設定的第 1～9 個頁籤與前後頁籤命令。macOS 預設 Cmd+1～9，Windows／Linux Ctrl+1～9；Ctrl+Tab／Ctrl+Shift+Tab 循環。依作用中分割區、目前 Session／Space、釘選優先的可見順序。第 9 鍵選第 9 個，缺少時無動作。HERDR 點選與快捷鍵共用啟用與失敗回復流程。
Terminal 焦點按目前頁籤及 active pane 的註冊身分取得 xterm。切回視窗與新建 Terminal 命名結束後恢复焦點；等待輸入面就緒，切頁、對話框及其他輸入欄位保留焦點。
HTML 預覽HTML／HTM 的檔案樹、檔案頁籤與編輯器右鍵提供「在此預覽」。沿用 Browser，預覽已存檔內容；同工作區成功存檔後 debounce 重載，保留手動重載。來源路徑與實際 capability URL 分離，工作區／Host 重連時重新取得資源權限。
資源與桌面 Browser原生 child webview 支援本機 capability、Host Runtime（WSL／SSH）及既有 SFTP backend。相對資源依 HTML 位置、根路徑依工作區解析。只讀 GET／HEAD，每檔上限 8 MiB；既有安全路徑邊界拒絕越界。遠端 localhost 仍由 Host tunnel 轉送。Browser 頁面無 App commands／plugin 權限。WebView2 明確轉換自訂協定載入位址。
元素上下文工具列可啟用選取外框，點選複製來源、selector、文字、HTML、尺寸及關鍵樣式；Esc 取消。支援同源 iframe、open shadow DOM；跨來源 iframe 以 iframe 本身選取。移除表單值與可編輯內容，輸出上限 32 KiB。本轮僅複製文字，不自動送 AI。
Git 操作回報僅針對忙碌型狀態讀取錯誤作有界重試；不重送提取、切分支、建立分支等寫入。操作成功與快照刷新失敗分開呈現，保留讀取重試與過期工作區請求防護。已透過真實 StatusBar／Popover 元件入口驗證，IPC 為測試替身；原始跨平台 GUI 故障尚未確認根因。
WSL 存檔確認 DrvFS 在 rename 時寫入 handle 尚未關閉，會讓後續 openat 暫時得到 ENOENT；磁碟實際已更新，但 Host 回傳 path-io-failed。修正為 sync 後先關閉寫入 handle，再檢查 revision、替換及重讀。另將同檔案並行遠端存檔序列化，保留更新的 dirty 狀態。

WSL 實機命令列證據

在既有 Windows 主機的 Ubuntu-26.04 執行 v0.0.14 Host --stdio，新建中文與空白檔名後，/mnt/c 與 /mnt/d 第一筆 FilesWrite 回報 path-io-failed，直接讀磁碟確認內容已寫入；/home 對照組成功。獨立系統呼叫驗證顯示，關閉 scratch writer 前 openat 為 ENOENT，關閉後立即可讀。

再由本次實際 Host files.rs、path_capability.rs、內容分類模組及新增回歸測試建立隔離的 Linux Rust 測試執行檔。前後版本只差 writer 的 drop(file)。每次測試均包含新建檔案、30 次存檔、磁碟位元組與回傳 revision 一致性、下一次存檔，以及外部修改衝突保護。

位置修正前修正後

/mnt/d失敗，path-io-failed通過
/home通過通過
