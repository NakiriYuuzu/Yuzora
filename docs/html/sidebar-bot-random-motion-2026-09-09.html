側邊欄 bot 隨機動作

2026-09-09：每個 bot 現在各自隨機選擇浮動、左右搖晃或點頭，並分別抽選眨眼、視線及身體動畫的週期與起始時間。

原因與修改

原本動畫使用固定週期，延遲只依外型區分，因此同外型的多專案 bot 會同步。現在由 SpaceCharacter 的 lazy state initializer 為每個元件建立獨立動畫參數，透過 CSS 自訂屬性播放；父元件重新渲染時保留參數，重新掛載才重新抽選。不同 bot 仍可能抽到相同動作，但各自的速度與起始時間獨立。

  • src/app/workbench/SpaceCharacter.tsx：初始化並套用每個 bot 的隨機參數。
  • src/app/workbench/space-agent-sidebar.css：使用獨立週期與延遲，加入左右搖晃及點頭動作。

沿用既有角色元件與 CSS 動畫，沒有新增 UI primitive 或 JavaScript 計時器；保留 portrait 小幅度動作、motion=false 及 prefers-reduced-motion 支援。
