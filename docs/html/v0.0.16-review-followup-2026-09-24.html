本輪修正

問題修正與證據
完整 Session 開啟期間的輸入可能亂序HerdrNativeDialog.tsx 將開啟前緩存與後續鍵入都送入同一 Promise 佇列。延遲第一個 IPC 的測試在修正前觀察到三次並行呼叫；修正後依序傳送，沒有重送。
事件斷線後，ready 狀態的恢復快照重播通知HerdrNotificationBridge.tsx 識別與 attention 同步替換的 baseSnapshot，保留側欄 attention、抑制 toast／系統／聲音通知。測試使用真正的 store applySnapshot 與 subscription event：恢復快照不通知，後續 working → done 仍通知。
MSSQL trigger 筆數干擾儲存格衝突判定dbStore.ts 只在 MSSQL 儲存格編輯的同一批次附加 SELECT ROWCOUNT_BIG()，讀取外層 UPDATE 的筆數，驗證完整單列回應並釋放 cursor。保留一般 SQL 的 aggregate counts。原 HEAD 的兩個差異測試分別重現「成功誤報 editConflict」與「零筆誤報成功」；修正後均通過。真實 MSSQL 測試涵蓋有 trigger、零／一筆更新與 NOCOUNT ON／OFF。
