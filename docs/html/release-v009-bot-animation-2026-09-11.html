v0.0.9 Bot 動畫設定

設定 → 外觀新增「Bot 動畫」總開關，控制 Space 夥伴的眨眼、表情、擺動與 hover 位移。關閉動畫後保留靜態角色，選擇保存於 appearance preferences。

預設與優先順序

沒有保存的動畫偏好時，邏輯核心不超過 4、可讀取的記憶體不超過 4 GB，或系統 reduced motion 都預設關閉；核心資訊缺失也採關閉。記憶體 API 不可用時依核心與系統設定判定。手動選擇會保留，系統 reduced motion 與個別 Space 關閉動畫仍優先。

實際瀏覽器驗證

使用獲授權的 Playwright，載入本次建置的 AppShell Demo。瀏覽器模擬 4 個邏輯核心與 4 GB 記憶體，頁面含 3 個角色。
