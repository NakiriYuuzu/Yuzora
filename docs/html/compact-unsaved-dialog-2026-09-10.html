縮小未儲存變更確認視窗

2026-09-10。原本的 ConfirmDialogHost 使用 unsaved-confirmation 縮放設定，預設占視窗寬高各 80%，使簡短的確認訊息留下大量空白。

修改

改用現有 shadcn Dialog 的內容尺寸：桌面最大寬度 420px，高度依訊息調整，四周保留至少 16px。移除該確認視窗的尺寸記憶 ID，舊的大尺寸偏好不再套用。

長檔名可換行；長訊息由 ScrollArea 捲動，按鈕區不被壓縮。儲存、捨棄、取消，以及 Escape／遮罩取消的既有流程保留。
