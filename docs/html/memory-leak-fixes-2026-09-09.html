變更內容

1. Channel 只在真正的 IPC 邊界建立

HERDR typed wrappers 直接傳遞事件函式，由 provider 在 native command 或 remote host stream 的實際 IPC 邊界建立 Channel。每個 Channel 都有 Rust owner，可在結束時接收 end 並解除 callback。已斷線的遠端請求在建立 Channel 前拒絕。

主機移除或 generation 更換會刪掉對應 streams 登錄；同一連線只更新名稱／設定時保留其物件 identity。closed 事件先驗證 owner，再做本地清理；過期的 release 仍可完成本地退場，輸入命令維持原本的 identity gate。

herdrProvider.ts · herdrIpc.ts · 回歸測試

2. 最後一個文件分頁離開時清理內容與 revision

新增 WorkspaceResourcesBridge，在 groups／workspace 轉場時比較仍開啟的文件，統一釋放被關閉的文件與遠端 revision。分割區整組關閉、非作用中文件關閉及 workspace 切換都會走這個流程；移動文件到另一組不會被誤刪。

documentRegistry 的每次讀取／reload 持有可撤銷 token。drop 或 clear 後，即使 I/O 晚到也不能重新插入快取；token 在 finally 清除，不累積已完成請求。drop 接受原工作區 identity，避免切換後清到另一個相同路徑。

WorkspaceResourcesBridge.tsx · documentRegistry.ts · 工作區回歸測試 · 文件競態測試

3. 遠端 workspace capability 有明確退場與保留期間

離開工作區會提出 release；如果仍有檔案 I/O 或暫時的 SQLite 瀏覽器持有 lease，等最後一個使用者結束才關閉 capability。清理會停止對應 watcher、移除 revisions 及 workspace 登錄，再呼叫 host 的 workspaceClose。進行中的寫入在驗證結果後才放開 lease，不重送寫入。

SQLite 檔案瀏覽器於卸載時釋放 lease，開啟結果晚到也會回收。資料夾選擇器取消後回收晚到的 capability；已選定工作區的有效性依主機連線判定，避免沿用已卸載對話框的 generation。回到仍活躍的工作區時不會因舊 release 請求而關閉它。

remoteFiles.ts · SqliteLocationFields.tsx · FolderPickerHost.tsx · lease／寫入回歸測試

4. PostgreSQL 按需讀取，讓 backpressure 傳回資料庫

刪除 unbounded row channel 與獨立 eager reader task。consumer 的 select 直接讀取 PostgreSQL RowStream；stdout 無法寫出、桌面停在第一頁時，就不再主動拉取後續資料列。既有 cancel、stop、closed 與錯誤處理保留，停止串流時直接 drain RowStream。

新增真實 PostgreSQL 回歸場景：SELECT repeat('x', 8192) FROM generate_series(1, 16384)，只讀取 500 列的第一頁，接著六次採樣 helper RSS。修正前同一測試在約 272 MiB 失敗，修正後約 20 MiB，並確認釋放後可再執行 SELECT 42。場景併入 PostgreSQL integration matrix，避免與同一測試程序其他 PostgreSQL helper 並行造成採樣混雜。
