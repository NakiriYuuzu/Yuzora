修正

  • 空且成功載入的 Session 顯示「選擇資料夾並開啟 terminal」，附上建立 Space／第一個 terminal 的說明。
  • 沒有選定 Space 時，「新增 terminal」沿用相同的資料夾建立流程；已有 Space 時維持原有新增分頁與重新命名流程。
  • 原生 Windows Session 清楚標示「Windows 本機 · default」；WSL／SSH 保留主機名稱與 Session 名稱。
  • 資料夾選擇固定目標主機。選擇期間若 Session 改變則中止，避免將 Windows 路徑送往 WSL。取消選擇不建立 Space；沿用既有未儲存內容確認。
  • 保留後端相容性 gate；載入中、unsupported、error、過期快照及 compatible=false 不開放新的終端入口。
