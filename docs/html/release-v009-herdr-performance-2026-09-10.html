瀏覽器量測

macOS 本機 Chromium、Vite Demo，注入 30 個額外分頁，共 31 個 xterm。直接 setActiveTab 後等待兩個 animation frame，20 次平均 35.835 → 33.315ms，最大 50 → 34.3ms。兩幀的時間下限約 33ms，故此數據主要用於確認沒有顯示退步，不作為跨平台加速比例。

最終以實際分頁按鈕連續切換 10 次，兩幀後量測為 29、25、33、33、33、33、33、33、33、34ms。共各 10 次 canonical path、workspace focus、tab focus 及 log 呼叫；終端機 connector 沒有重新開啟或釋放。確認作用中的 Perf 1 顯示既有輸出與 shell prompt。

Demo 使用模擬 IPC，以上不包含 Windows WebView2 或遠端 host 往返延遲。未改變 native focus 的順序、latest-intent guard、未儲存確認或錯誤回復；不同 Session／主機與真實 Agent 的切換仍需新候選實機驗收。原始 JSON、量測腳本及畫面保留於本機 output/release-v0.0.9/herdr-*。

macOS App 從 v0.0.9 僅支援 Apple Silicon

依使用者確認，candidate 與 release App 改為 aarch64-apple-darwin，CI 檢查主程式 Mach-O 僅含 arm64。Intel macOS 遠端 Host 仍保留，舊版已發布 artifacts 不變。AGENTS.md、operations、README、中英文官網與 updater 同步此政策；新版 metadata 不含 darwin-x86_64。

固定下載名稱改為 Yuzora-macos-aarch64.dmg。Tauri CLI 2.11.4 產出的 Yuzora.app.tar.gz 與簽章於發布收集步驟成對改為 Yuzora_<version>_aarch64.app.tar.gz，避免 metadata 找不到版本化檔案。測試實際執行 workflow 的收集 shell，將假 installer／archive／signature 交給 metadata generator；macOS CI 負責真實 Mach-O 架構驗證。

Release contract 另有負向測試，拒絕重新引入 Intel／universal App。網站不以 MacIntel user agent 推測 CPU；僅明確的 x86 client hint 拒絕自動下載，下載說明清楚標示 Apple Silicon 限制。

交付邊界

本機完整前端驗證：196 個 Vitest 檔案、2,351 項測試通過；typecheck、lint、App／Demo build 與 release contracts 通過。ESLint 保留既有 51 項 warnings。

此修正尚須包含於新候選，44ca15f 與更早安裝檔不能代表本次結果。Windows 舊圖示回報尚待安裝端路徑／捷徑及截圖定位；未宣稱已修復。Stable macOS 仍須六項 Apple signing secrets 及正式簽章驗證。PR 需等待使用者候選驗證與明確 merge 核准。
