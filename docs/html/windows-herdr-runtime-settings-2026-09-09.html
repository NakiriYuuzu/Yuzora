使用方式

Windows 本機

設定 → HERDR → Windows 本機。可選 Yuzora 管理、主機已安裝、或自訂 herdr.exe。檢查後套用；來源變更重啟 Yuzora 生效。

WSL

設定 → HERDR → 啟用 WSL HERDR，再選 Ubuntu-24.04。檢查目前與目標 client，更新主機工具。新增資料夾時明確選 WSL。

不相容

從錯誤按「修復此主機」，核對 exact binary、client／server protocol 與每個 running Session。可複製診斷；不自動停止 server。

四項防護

  1. 設定直接管理主機工具、更新／重新偵測、複製診斷，分開顯示目前 client 與目標版本。
  2. 錯誤提供「修復此主機」，以 hostId 定位，介面顯示主機名稱與 Session 名稱。
  3. 來源政策與解析 binary／helper 路徑分開保存；管理套件差異顯示可更新；已安裝來源缺失不回退。
  4. 套用前重新驗證 schema 與所有 running Sessions，失敗保留原設定；server 需要更換時先保全工作並確認受影響 Session。
