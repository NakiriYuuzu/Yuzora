HERDR 新版與 Yuzora 整合狀態

建議以 0.9.3 作為穩定版基準。0.9.2 帶來主要改進，0.9.3 修復鍵盤回歸；大量 agent 的 Linux 遠端負載仍有未解回報。Yuzora 工作目錄已設定 0.9.3，但不能據此判定所有執行中的 server 都已升級。

已發布內容

官方 latest 為 v0.9.3，發布時間為 2026-09-29 19:29:23 UTC，即台灣時間 09-30 03:29:23。查證時未見更晚的穩定 release。

版本／面向主要變更
0.9.3：快捷鍵修復恢復 Escape 前綴按鍵；包含 macOS Option 逐字移動／刪除、部分 Claude Code Shift+Enter 換行，以及 Alt+[ 快速連續輸入。
0.9.2：效能與遠端改善多 pane CPU、Git 查詢造成的輸入停頓、SSH 傳輸與畫面差異更新；增加 machine status／reconnect。
0.9.2：Session 與 agent支援 agent 自報 resume command、錯開啟動還原；保留最多 48 份 layout snapshots，改善狀態判定與通知。
0.9.2：終端與 Windows改善 Kitty 圖片、重繪與輸入；Windows 優先使用 pwsh，修正多行貼上及 Shift+Enter。
0.9.2：整合契約移除 pane.graphics.*，改用標準 Kitty graphics；terminal control 支援 terminal.mouse；訂閱落後時明確回報 events_lost。

依據：0.9.2 release notes、0.9.3 release notes。以上是上游發布說明，不代表 Yuzora 各條 transport 或 UI 路徑已逐項驗收。

目前仍需注意的狀態

  1. 多 agent 高負載尚不能視為解決。#4506 的最新回報於台灣時間 10-02 指出，0.9.3 在 Linux 高核心數主機及大量活躍 pane 下仍出現高 CPU，且 remote client 反覆因健康檢查逾時而重連。這是特定環境的使用者回報，本次未重現，不能推廣成所有 Linux 主機都會發生。
  2. 遠端剪貼簿仍有未解案例。#4833 回報 0.9.3 的 macOS SSH 選取文字寫入遠端剪貼簿、本機未更新。這是官方 client 的路徑，尚未確認 Yuzora 是否受同一原因影響。
  3. master 與 stable 必須分開。Windows 原生可點擊通知 #4803 於 09-30 合併，晚於 0.9.3 發布；不應把它列為 0.9.3 的已發布功能。分支比較顯示 diverged；提交數不等於尚未發布修正數，可能含 release 同步或重複移植。

Yuzora 當前整合狀態

層次本次確認意義
目前工作目錄herdr-runtime.json 的 baseVersion 是 0.9.3，protocol 是 22，五個 host 平台資源均指向該版本。整合設定已追上最新 stable。
目前 HEAD以 git show HEAD:src-tauri/herdr-runtime.json 確認 baseVersion 仍為 0.9.1。0.9.3 升級存在於未提交工作目錄，不能當成已提交或已發行成果。
相容性與訂閱runtime gate保留 client、schema 與 running Sessions 相容性檢查；HerdrBridge 遇到 error／disconnected 會重新訂閱並刷新。靜態程式有相容性與錯誤恢復防線；不構成本次端到端驗證。
既有驗證紀錄同日升級紀錄記載 0.9.3 同版與 0.9.3 client／0.9.1 server 的隔離契約驗證通過。引用既有紀錄；本次沒有重跑。該紀錄仍列出 GUI、Windows／WSL／Linux 實機驗收缺口。
實際執行環境本次未探查使用者的本機或遠端 running Sessions。各主機 server 的有效版本未知。

Yuzora 操作文件明確區分隨附版本、選定 client 路徑與既有 server。升級 client 不會自動替換執行中的 server。官方也區分持續執行、停止後還原與 experimental live handoff；Session state 文件說明一般 server restart 不保留原程序。

評估與優先順序

0.9.3 是合理的 stable 整合基準，但目前證據不足以宣告大量 agent／SSH／跨平台部署已全面穩定。Yuzora 下一步的重點是確認各主機實際 client／server 版本，再驗收高 pane 數負載、滾動、快捷鍵、剪貼簿及重連；沒有足夠理由僅為追新而改用 preview。上游 CPU 改善與 SSH 優化，也不能替代 Yuzora 自身 helper／stream 路徑的驗證。
