渲染修正

  • Transport 保留 frame 寬高，在 output queue 寫入對應完整 ANSI frame 前才調整 xterm grid。字型或容器 fit 只發布 server 尺寸，不先重排舊畫面。
  • 等待有效容器尺寸與字型量測才建立 controller；初始量測未就緒時重試。連線建立不再依賴可能被 WKWebView 暫停的 animation frame。
  • 以 80ms debounce 合併 sidebar／分割 pane 的暫態尺寸，避免把中間狀態傳入 PTY。
  • 沿用 HERDR synchronized full frame 原子重繪，避免每次完整畫面前清空 xterm。
