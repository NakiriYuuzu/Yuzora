Space 右鍵選單：上移／下移

2026-09-14 · release/v0.0.14 · 基準 e6579f78e1271b22570df02ce0fa5977ff735b04。此為既有候選分支的增量修正，未發布正式版。

行為與修改位置

Space 根列及工作區列的右鍵選單新增「上移／下移」（英文 Move Up / Move Down）。移動限制於同一 Session，相鄰目標依側邊欄 root group 順序解析；不跳過 metadata 不完整的相鄰群組。第一個 Space 停用上移，最後一個停用下移。linked worktree 不可獨立移動，附停用原因；root 以 workspace.move_block 移動完整群組。

src/lib/herdrWorkspaceActions.ts 共用 drag／選單 mutation，沿用 optimistic order、權威回傳、單次 snapshot reconciliation 及明確 unsupported 才 legacy fallback 的規則。同 Session 進行中的操作不重複送出。herdrWorkspaceReorder.ts 解析相鄰群組；SpaceAgentTree.tsx 與 contextMenuDefs.ts 接入既有選單；兩份 menus.json 提供雙語文字。

Typecheck 與 CI 實際診斷

修改前，本機 bun run typecheck（TS 7.0.2）與 TS 6.0.3 的 src 型別檢查均通過，未重現原先描述的型別錯誤。最新基準 CI 的 Typecheck 步驟亦通過，真正失敗為 release-contract.test.ts 的單一六案例 fixture 超過 5000ms。現將六個 subprocess fixtures 分成獨立測試，保留簽章、版本及 artifact 拒絕驗證，子程序另設 4000ms timeout 並檢查 error/signal。

完整測試另捕捉到 HerdrTerminalPage 的 Profiler 案例偶發計入尚未完成的 mount commit；已先等待非同步初始化完成，再同步測量單一 attachment store 更新。未修改 Terminal 實作或降低重繪斷言。最終完整執行全部通過。
