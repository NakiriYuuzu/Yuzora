資料庫介面重新設計

Yuzora Database workbench，2026-09-23。範圍：左側連線／物件導覽、右側 Query 與結果區、Catalog picker、surface CSS 與 i18n。

設計判讀

Surface archetype：Operate（Command + Inspect）。使用者在同一個畫面中挑選連線、瀏覽物件、寫 SQL、讀結果與編輯資料格；介面的工作是讓資料本身成為主角，而不是展示卡片與容器。

方向：放棄舊版「多張圓角卡片、各自陰影、玻璃導覽」的呈現，改成一張連續的扁平工作面：外層只有一個 card，內部用 1px 分隔線切出導覽、Header、編輯器、結果與狀態列。密度參考 Linear／Supabase table editor 的語彙，但不複製其品牌。

  • 單一 radius 系統（--r-xs 列、--r-lg 外框）與單一 accent。
  • 狀態點只在承載連線狀態時出現；已連線／離線文字對螢幕閱讀器保留。
  • 數值欄位右對齊、tabular numbers；行號 gutter 固定於左側且 aria-hidden。
  • 無大寫 micro-label、無 accent rail、無裝飾性分隔符；可見文案不使用 em-dash。
  • 支援 prefers-reduced-motion；hover／selected 以 color-mix 疊在 --ink-0，深淺主題皆成立。
