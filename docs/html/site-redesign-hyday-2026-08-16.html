目標與流程

依 hyday.tw 風格重做 site/（GitHub Pages 宣傳頁）：light 主題、精緻動效、zh-TW 優先雙語。流程契約全數走完：single-html 預覽（七輪迭代）→ 使用者拍板 → 重構正式 site/ → 本機瀏覽器 RWD 驗收。

預覽迭代重點（七輪）

  • hero 進場編排、kicker 逐字、滑鼠視差、mini Command Palette、技術 marquee、GitHub stars 實時 badge、CSS scroll-driven progress bar。
  • terminal-git 影片兩度重製，1:1 對齊新版 git 面板（tabs／SVG git graph／RefChip／CommitDetails），敘事＝cherry-pick 長節點 → push 後 origin/main 跟上。
  • 影片下緣 git-tail 線串流衍生至 bento git graph（真實 lane 色、draw-in＋流動）。
  • boundary flow-diagram 置中＋IPC 封包光點雙向穿梭＋lane 進場動畫。
  • 四顆 float 藥丸（含 icons）：捲動第一個像素即開始重力落體至 hero 底部，續捲後飛進「開一個 Space」卡片被吞掉（卡片綠環吞嚥動畫）；全程 CSS scroll-driven（scroll()＋timeline-scope named view-timeline 雙軌）。
  • 拍板前最後修訂：移除 Apple Silicon 晶片卡。

Dark / Light mode（收官追加）

  • 機制：html[data-theme] tokens 覆蓋層（surface／ink／line／shadow 全套暗色化，--accent-ink 於深底改亮綠 #a9d64d 維持對比）；head inline script 於 CSS 前套用主題防 FOUC；color-scheme 同步。
  • 行為：預設跟隨系統（prefers-color-scheme，含即時跟隨系統切換），使用者按 nav 太陽／月亮鈕後存 localStorage yuzora-theme；meta[theme-color] 隨主題切換。
  • 寫死色修正：nav 玻璃底、float 藥丸、marquee logo（dark 用 invert 反轉、hover 回品牌色）、GitHub icon、git-tail 節點 ring、bento-e 漸層、IPC state 封包、hero 暮色光暈；夕空下載島與深色按鈕改為模式不變的字面色。
  • 連帶修正：主題鈕使 390px nav 溢出——CTA 加 nowrap、≤520px 縮成圓形箭頭鈕（aria-label＋data-i18n-aria-label 補語意，applyLang 新增 aria-label i18n 支援）。
  • 驗證：headless 預設 dark 證明系統跟隨生效；重載持久化 ✔、light 回歸無破壞 ✔、dark 六區段截圖 ✔、390 無溢出 nav 62px ✔。順帶移除 app.js 內與 downloads.js 重複的舊 platform-detect 區塊。
