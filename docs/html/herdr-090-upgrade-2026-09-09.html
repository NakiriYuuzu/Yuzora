避免再次發生的研究

完整研究與主要來源固定查核官方 HERDR v0.9.0 source。短期措施如上；中期建議把 managed／installed／explicit 來源政策與 binary／helper 解析路徑分開，保存 artifact identity、驗證時間與上一個有效版本，再評估穩定 endpoint generation。

endpoint_compatible 不能替代 private protocol compatible；restart_needed=false 不代表舊 private connector 可用，server_binary_stale 也只表示版本不同。這些語意已在研究中分開說明，中期設定與 transport 遷移尚未實作。

更新後的唯讀證據（PowerShell）

installer 請填實際安裝的檔案；HERDR 路徑請從更新後的 Yuzora 主機設定複製，勿沿用舊變數或從 PATH 另找 binary。以下不會停止 server。

$Installer = Read-Host '實際安裝的 MSI 或 EXE 完整路徑'
Get-FileHash -LiteralPath $Installer -Algorithm SHA256
$YuzoraHerdr = Read-Host '更新後 Yuzora 選用的 HERDR 完整 Linux 路徑'
wsl.exe --distribution Ubuntu-24.04 --exec id -u
wsl.exe --distribution Ubuntu-24.04 --exec sha256sum -- $YuzoraHerdr
wsl.exe --distribution Ubuntu-24.04 --exec env HERDR_SESSION=default $YuzoraHerdr status --json
wsl.exe --distribution Ubuntu-24.04 --exec env HERDR_SESSION=default $YuzoraHerdr session list --json
