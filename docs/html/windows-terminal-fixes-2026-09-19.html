根因與修補

問題證據與處理
Windows 改字級擠字以 400 行輸出，26px → 10px 重現整行擠到左側。正式 HERDR 元件加固定 frame，以及直接更新 xterm 字級，均能在 Windows WebView2 153 重現。字級已改變時，重用的隱藏量測節點仍同步回傳前一字級寬度，錯誤結果被快取。補丁在字型變更時重建四個量測 span 及其容器；不重建可見 terminal、buffer 或 Session。
返回 App 沒有鍵盤焦點native activation 現在不以 document.hasFocus() 為唯一判斷：確認原生視窗仍作用中後，要求 main WebView 取得鍵盤焦點，再恢復當前 pane。DOM focus 不重複發出 native 請求。相關取消與重入案例已通過；修補後的 Windows 安裝包仍待實機確認。
命名／信任提示關閉後沒聚焦命名輸入尚未卸載時保留等待；普通輸入欄仍終止恢復。新工作區信任提示允許或取消後，對提示開啟前的頁面發出焦點請求；已切頁則取消。
Browser 蓋住未儲存確認框中央 overlay gate 漏接 confirmDialog store。已補接，並測試 Browser 已開啟與開啟中兩種情境：確認框存在時隱藏 native child，取消後恢復。

驗收界線

Windows 原生字級驗證使用同一份 production HERDR 元件與真實 xterm，僅替換 IPC peer；不是更新安裝包後的完整 App 驗收。新候選須優先重測 R1／R2、F1／F2、B8。原有 Git、WSL 與 Browser 的有限 smoke 結果不提升為整列矩陣通過；其餘待測項目保留。

全程使用 Codex Browser／computer-use，Windows App 未被額外 Raise 至 macOS 前景；沒有使用 Playwright 或停止現有 HERDR Session。
