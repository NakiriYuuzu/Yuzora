原生 Session 決策

官方 HERDR v0.9.1 的 terminal session connector 忽略 Graphics 訊息，native popup 沒有一般 pane ID。完整 Session 使用所選 binary 的 herdr --session … client；此模式只連接既有 server。PTY 僅承載官方 client，未新增獨立 shell runtime。開啟期間暫停同 Session 的一般 pane connectors，關閉後恢复；釋放 client 不停止 HERDR server 或 Agent。

使用一般 xterm identity 與 inline graphics，避免上游的本機檔案傳輸最佳化。圖像合計上限 64 MiB、128 張與 512 個 placements；畫面佇列上限 8 MiB。Copy mode 的 OSC 52 只處理寫入剪貼簿，不回覆剪貼簿讀取。

本決策已補充至 .yuuzu/adr/0004-herdr-terminals-browser-only.html，並更新 glossary、README 與 operations。它取代舊有對 Agent 啟動表單與停止中 Session 管理的排除。

主機與生命週期
  • 所有 mutation 使用封閉的 Rust／TypeScript request union、官方 schema／capability gate 與明確 named Session。
  • Agent wait、Plugin install 等長操作走獨立 helper control lane，保持一般遠端檔案通道可用；連線 generation 過期時捨棄回應，不重送操作。
  • 成功 mutation 的後續刷新失敗另行顯示，不誤報成 mutation 失敗。
  • Windows PowerShell 使用 .NET BaseStream 轉送 UTF-8／二進位，不經 native-command 文字管線。Windows Session 啟動沿用官方 launcher 的 detached daemon／SSH job 處理。
  • Windows 路徑保留主機與 workspace root identity；檔案操作使用 pinned handle，拒絕 reparse traversal。
  • 保留既有 Intel macOS 遠端 helper；macOS App 仍僅支援 Apple Silicon。
