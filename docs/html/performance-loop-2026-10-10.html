環境與比較方法

Apple M2 Pro、12 CPUs、16 GiB、macOS 27；Bun 1.4.2、Rust 1.96、Yuzora 0.0.18。起點 HEAD：6cb7f01237a56b69f49cbee722507202c29ef7a4，起始 tracked tree clean。保留所有非本輪資料與既有程序；沒有 Git 寫入。各候選與該輪目前最佳版本在相同 optimized／production 模式比較，至少五次配對，另以同版控制校準噪音，必要時增加樣本。

固定資料包含千檔案樹、5,000 行編輯器文件、10,000-row SQLite、32B～1MiB transport、128 spaces×8 sessions／8×1、0/1/8/64 iframe。基準串行執行；冷程序／fresh document／暖機後結果分開，沒有把開發模式與 release 混比。生命週期先暖機後至少 100 次；無強制 GC、無中途程序重啟或清空使用者狀態。每輪保存原文、candidate、patch、hash、原始樣本、正確性檢查與撤回理由。

保留標準為至少一個實質目標超過 5% 且超過噪音，並檢查絕對差、個別情境回歸及資源釋放。沒有加權總分。保留案例的單一功能收益不能直接相加為整體 App 加速。
