外部 HERDR Space／Agent

原本 activateSpace／activateTab 在缺少檔案根目錄時要求選資料夾，導致使用者無法直接進入外部已建立的 terminal。現在缺少檔案根目錄仍可聚焦 HERDR Space／tab，顯示既有 Terminal Sessions。Space 選取會呈現該 Space 的可用 tabs，並維持其 active tab。

沒有根目錄時保留目前 Files 工作區，不從 Agent cwd 猜測路徑，也不彈出資料夾選擇。已有根目錄的專案仍走既有工作區切換與未儲存檔案保護。背景自動恢復保留前次修正，不替使用者主動選取新的資料夾。

終端分頁「×」

原先只移除畫面與解除 connector，HERDR tab 仍存在。現在先驗證對應 session 與 tab.close 能力，使用與右鍵關閉相同的冪等關閉 API，成功後才釋放 connector、移除畫面並刷新 topology／snapshot。

重複點擊不會重複送出。精確符合目標 tab 的 already-closed 回應視為成功；其他錯誤保留分頁與 connector 並顯示訊息。操作只針對點擊分頁的 HERDR tab，不關閉整個 Space 或 server。App 退出仍僅釋放自己的連線。

驗證

修正前新增測試可重現 6 項失敗；修正後 herdrStore 與 TabBar 的 72 tests 全數通過。涵蓋無檔案工作區、已有檔案工作區、外部 Agent、Space 多個 tabs、第二個 terminal 的 runtime-first 關閉、already-closed、連點與關閉失敗。

完整前端回歸測試：186 檔、2,221 tests 全數通過。

Typecheck、production build、修改檔案 ESLint 與 git diff --check 通過。Build 保留既有大型 bundle／dynamic import 警告。未執行 GUI、真實 terminal 程序終止或跨平台 E2E；開發伺服器已確認提供新版關閉邏輯。
