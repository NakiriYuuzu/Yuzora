保留的功能與工作流程

HERDR terminals：named Sessions、Spaces、Agents、BSP panes、輸入輸出、control／observer、resize、scroll、字型與 IME、connector 釋放與重連。App 關閉仍保留 HERDR 持有的 server 與程序。

Browser：網址輸入、導覽歷史、上一頁／下一頁、重新整理、原生 webview、面板可見性與遠端 loopback tunnel。保留 native session generation 與延遲回應防護；內部仍使用部分 preview 命名。

其餘工作面：CodeMirror 語法編輯、工作區文字搜尋、Markdown／SVG／圖片檢視、Git、Database、SSH 認證與 host helper、SFTP 傳輸及檔案編輯仍保留。

需要開發伺服器時，在 HERDR terminal 啟動，再將網址貼入 Browser。編輯器已不再提供 LSP 智慧編輯與 LSP 格式化。

Profile migration、Windows workspace migration、installer legacy-cleanup payload 與現行 capability fallback 仍有 production caller，繼續保留。歷史 ADR、研究報告與 log sanitization fixtures 可能仍提及舊功能；這些內容不會重新啟用已刪除的執行路徑。
