HERDR 工具、側欄與資料庫介面重新設計

2026-09-23 · 範圍：src/ 前端 · 未進行 Git 寫入

重點：這一輪完成了六項需求。HERDR 工具改成「範圍麵包屑＋左側工具導覽＋編號步驟」的呈現方式，不再疊放一堆下拉選單；側欄加上各 Agent 的 Logo；資料夾選擇會直接開啟系統對話框；資料庫介面改成類似 Surrealist 的卡片式版面。typecheck、lint、測試、build 都已通過，也在實際 App 中用 computer-use 確認過。

六項需求與處理方式

#需求處理方式
1Worktree modal 下拉選單太多HerdrToolsDialog：Header 改成「主機 › Session › Space」麵包屑，Space 只在需要時出現；右側放「開啟 Herdr 視窗」按鈕；工具改成左側直式導覽並加上圖示。WorktreeTools 拆成「1 建立 → 2 既有 Worktrees」兩個步驟，列表使用 shadcn Item，並以 badge 標示主 checkout／已開啟狀態。
2「開啟完整的…」改名選單與 Dialog 的文字統一為「開啟 Herdr 視窗」（en：Open Herdr Window）。
3搬移 Pane 不直觀改成三個步驟：選擇來源 Pane 卡片（顯示 Space · 分頁 · paneId，並標示目前焦點）→ 選擇目的地（三張附圖示的卡片）→ 放置位置（分頁卡片＋左右／上下分割圖示切換，或 Space 選項）。底部摘要列會顯示「來源 → 目的地」。
4Spaces | Agents 區塊精簡，並加上 Agent Logo移除外層 Card，把切換、工具與新增按鈕併成一列；Agent 列改成單行，包含 Logo、狀態點與狀態標籤。共 19 個 Logo，來源為 @lobehub/icons-static-svg（MIT），其餘改以字母圖示代替。
5新增資料夾會多跳一個 modal本機（非 Windows）直接呼叫系統的資料夾選擇器。Windows、遠端與 WSL 仍保留原本的 modal，因為這些情況需要先選擇原生或 WSL、或者選擇遠端路徑。
6Database 改用 Surrealist 風格的 GUI頂部改成連線列（連線名稱 › 資料表，加上連線狀態標籤、引擎與位址）；查詢與結果改成兩張可調整大小的卡片，「執行」按鈕移到查詢卡的 header，結果卡的 header 顯示 statement 數與耗時；物件樹加上帶底色的圖示、群組數量，並標示目前開啟的資料表；也修正了區域之間多餘的空白。
已取代：「兩張卡片」版面由較新的 database-redesign-2026-09-23 的單一 card surface 取代。

限制與後續

  • 實際 App 中沒有已儲存的資料庫連線。為了不改動使用者設定，已連線狀態的卡片版面只在 Demo（SQLite 範例）中驗證。
  • droid、letta、maki、muse、omp 目前沒有官方 Logo 可用，因此使用字母圖示。
  • 工作區原本就有未提交的變更，這一輪沒有執行 git add、commit 或 push。
