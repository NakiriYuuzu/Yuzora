Spaces 與 Agents 側邊欄操作調整

2026-09-10 · 實作與驗證紀錄

Spaces 與 Agents 標題、目前 Herdr Session 範圍與新增功能整合為卡片。每個 Session 可獨立收合或展開 Spaces，各分支右側的「＋」用來新增 terminal。

操作變更

位置完成行為
Spaces 與 Agents 卡片顯示「全部 Herdr Sessions」或目前主機與 Session 名稱。下拉選單負責切換範圍與重新整理。
卡片右側「＋」提供「開啟資料夾並建立 Space」與「加入 Herdr Session」。Session 視窗保留已連線清單，並提供 SSH 遠端主機與 Windows 的 WSL 入口，可連接其他主機再載入其既有 Session。
Session 標題列每個 Session 都有獨立的收合／展開按鈕，只影響該 Session 的 Spaces；空 Session 按鈕停用。移除「已載入快照」與 All 的 runtime namespace 提示，保留錯誤／斷線資訊。
分支列右側常駐「＋」，使用該分支所屬的主機、Session 與 Space。開啟後沿用既有 terminal 分頁與命名流程。
空 Session沿用指定主機的資料夾選擇器，按鈕名稱同步為「開啟資料夾並建立 Space」。
鍵盤操作保留樹狀方向鍵導覽，聚焦分支後可使用 Tab 移到新增按鈕；按鈕提供主機／Session 與分支名稱。

建立流程

使用既有 activateSpace 完成切換與未儲存內容確認，再檢查選取目標與 runtime 能力。取消切換或目標改變時不建立 terminal。處理期間停用重複建立；錯誤顯示於側邊欄。離線、不相容或缺少建立能力的 Session 停用「＋」。

加入 Herdr Session 時先重新整理既有清單。SSH 頁籤沿用 HostList，可新增／編輯主機與使用既有密碼、金鑰及主機驗證流程；連線後沿用 hostStore.setup 與 RuntimeSourceFields 設定 Herdr，重新整理並只列出所選主機的 Sessions。已連線的 runtime 可直接載入，不重複部署主機工具。

Windows 的 WSL 頁籤先檢查原有 opt-in 設定，再探索發行版；WSL1 無法選取。原本的已連線清單仍可選取本機或已連線遠端主機的 Session。停止中的 Session 無法載入；成功後更新卡片與樹狀清單，失敗則保留視窗與錯誤。

驗證

  • 5 個測試檔、65 項測試通過：HerdrSessionPicker、Space／terminal 建立、樹狀導覽、Session 狀態及面板整合。
  • 回歸測試先確認舊視窗缺少 SSH 遠端主機入口，再驗證補回後的新增主機、密碼驗證入口、主機設定、Session 隔離、不相容錯誤、舊 SSH transport 拒用、WSL opt-in／WSL2 與關閉後的延遲回應。
  • bun run build 通過，包含型別檢查。Vite 回報 chunk 大小與既有 remotePreviewUrl 匯入方式警告。
  • 本次 Session 選擇與遠端主機修正的程式及測試 lint 無錯誤、無警告。
  • git diff --check 通過。
  • 尚未執行真實 SSH／WSL 連線，以及瀏覽器／E2E 或桌面實機視覺驗證；使用者提供的 AGENTS.md 要求瀏覽器／E2E 事先取得明確同意。
