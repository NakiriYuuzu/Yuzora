  • 一般 TypeScript 6.0.3 與 native TypeScript 7.0.2 分流；目前 lint parser 的 TS peer 尚不支援全面改用 TS7。

實測發現與最小相容修正

  1. CSS／SCSS 函式高亮：新版 Lezer 下原本泛用 Callee 規則未取得預期優先權。於 src/editor/cmExtensions.ts 改成 CallExpression/Callee，未放寬普通 token 著色。原 production corpus 的 3 個失敗已先重現，原斷言保留後全數通過。
  2. 新版 Clippy 的 async 大型錯誤診斷：src-tauri/src/db_profiles.rs 的 ProfileError.error 改為 Option<Box<DatabaseError>>，直接承接底層 Box；保留 code／message 與 JSON 形狀。新增 size 回歸測試，並加上完整序列化 equality。
  3. 測試程式相容性：src-tauri/src/host_windows.rs 的 UTF-16 測試改用 as_chunks<2> 並驗證沒有剩餘 byte；src-tauri/host/tests/sqlite_stdio.rs 只將測試 helper 的大型 error 包裝為 Box，不改 wire protocol 或正式程式邏輯。
  4. Clippy baseline：先用舊 baseline 驗證修正後只有 missing 診斷，再刪除 36 個確實消失的 fingerprints（71 次 diagnostics）。保留其餘 14 fingerprints／19 diagnostics，包括原本 dirty worktree 的 SSH 行號調整；沒有新增 suppress／allow 或豁免。
  5. 歷史 release recovery：從原始 source SHA 的 Host matrix 選取 macos-14／15 job 名稱；未知、缺失與重複 runner fail closed。測試涵蓋新舊成功及錯誤分支，不以新 runner 名稱覆蓋歷史契約。

新增 scripts/dependency-contract.test.ts 守護 compiler split、overrides、patch、Remotion pairing、工具鏈設定；scripts/release-contract.ts 與 scripts/release-recovery.test.ts 同步 Actions／recovery 契約，docs/operations.md 同步運維說明。

暫緩項目與剩餘安全風險

  • russh 0.63.3 暫緩：新 host-key／certificate API 需要先定義信任政策；保留 0.62.7 lock，不改動既有 SSH 認證工作。
  • Tiberius 0.13 暫緩：本地 0.12.3 fork 有 10 個實際修改的 Rust 檔案，須重新驗證 TLS provider、timeout、精確 MONEY／SMALLMONEY、DONE_COUNT 與 EOF rows_affected。不能直接替換或只依 fork 文件判斷。
  • TypeScript 6 保留：不是漏升級；TS7 native 已用於專案 typecheck，普通 TS6 留給相容的 lint compiler API。

更新後對兩個 Cargo locks 共 770 個 public crate/version 身分（含 Tiberius 上游基底）查詢 OSV，5 個身分仍命中 11 個公告 ID；其中部分 GHSA／RUSTSEC 是同一問題的別名。這不是 11 個獨立可利用漏洞，也不是完整漏洞保證。
