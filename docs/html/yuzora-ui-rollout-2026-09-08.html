平行開發與整合方式

依使用者指定，三個 gpt-6-astra / low 各自負責有明確邊界的元件。主 agent 負責外殼、依賴、整合與瀏覽器驗證。開發凍結後由一個 gpt-6-astra / max 獨立審查；問題交回原分工修正，並由同一 reviewer 複查。

分工責任與交付
Spaces / AgentsSpace → worktree → Agent 樹、完整 Host + Session 身份、All 已載入集合、獨立 Inspector、角色外觀編輯、啟動入口與原 capability gates。
Editor / Git / TabsRich Markdown 與 CodeMirror 共用文件、工作分頁釘選、Git 多選與大型並排 diff、原 Git graph、Terminal 新增分頁及不停止 runtime 的關閉投影。
Settings / Theme分類設定與搜尋、JetBrains Mono 預設字型、持久化主題與多點漸層、真實資源分類、窄視窗狀態列。
Root integration雙側欄 AppShell、共用工具上欄、面板 mount / focus / resize 保護、整合測試、隔離 fixture、證據與本紀錄。

正式接線後的行為

  • 左側 Spaces 與 Agents，右側 Files / Git。資料庫、SSH / SFTP、搜尋和設定移至頂列。右側可開啟原有 Git 提交紀錄與 branch graph。
  • All 只是已載入 runtime 的展示篩選，沒有創建新的跨 Session runtime。工作目錄、worktree 與 Agent actions 維持完整 Host + Named Session scope。
  • Markdown 預設文件模式，可切原始碼。TipTap 編輯透過 CodeMirror transaction，保留既有儲存、undo、LSP 與 remote revision 路徑。不支援無損 roundtrip 的 HTML、frontmatter、圖片／引用等內容回退至安全閱讀與原始碼。
  • Git 檔案單擊或 Enter 開啟共用 DiffModal，預設並排、首次近滿版；使用者調整過的尺寸仍會保存。多選暫存沿用原 store 與實際 Git 操作。
  • 刪除為灰色、未追蹤為醒目暖棕、已暫存為綠色、修改為藍色，另有文字標記。明暗主題使用各自的可讀色票。
  • 右鍵可釘選，批次關閉保留釘選。跨重啟持久化目前涵蓋檔案分頁；Herdr / Preview 的釘選維持本次 UI session。
  • 新增分頁提供 Herdr Terminal 與 Browser。既有本機終端機 drawer 保留，避免在 UI 遷移中遺失已存在的 PTY。關閉 Herdr 工作分頁只釋放 attachment；明確停止 runtime 的操作仍走原控制與確認流程。
  • Terminal 字型預設使用已 bundled 的 JetBrains Mono；文字大小與字型立即更新既有本機與 Herdr terminal renderer，不以重新啟動 process 套用。Shell profile 明確只適用本機終端機。
  • 資源視窗使用 PerfSnapshot 的 App、WebView、受管工具三分類。沒有假造逐 PID、Space 歸屬或遠端用量。畫面說明其觀測範圍。
正式 domain 以 accepted ADR-0003 為準：Linux / macOS、Windows WSL2 與 SSH HostRuntime 使用完整 hostId + sessionName。沒有將舊 Demo 的 Windows-native 模型、AgentZone 或 mock runtime 搬入 production。

結論與尚未覆蓋的驗收

品牌延續：可進下一階段。紙色、暖深灰、Space palette、三種既有字型及四角漸層仍可辨識；閱讀面保持穩定。ADE：source 與 frontend fixture 審查後可進原生驗收。五項 review 問題已修正；完整 runtime 驗收仍有證據缺口。

  • 真正 200% browser / OS zoom 尚未執行。720×450 僅為 1440×900 在 200% 時近似的有效 viewport，不標為 zoom PASS。
  • 沒有啟動 live Herdr，因此四個 panes、observe / control / takeover、agent 替換與重連的原生 terminal input、IME、scroll、resize 仍待實機驗收。
  • Native Preview webview 疊層、焦點與快捷鍵；遠端文件 owner / revision / save；DB / SSH / SFTP 完整流程未實際操作。現有 source gates 與單元測試不能替代這些驗收。
  • Browser fixture 的 graph 入口可達，原 Git graph 實作保留；本次沒有用真實 Git history 操作或提交。沒有實際執行 staging、commit、checkout 或刪除。
  • 全部 palette、全狀態、完整 Tab / Shift+Tab 與螢幕閱讀器矩陣尚未逐項跑完。僅對本文列出的操作與圖面下結論。
