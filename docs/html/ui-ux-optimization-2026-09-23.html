Yuzora UI/UX 深度分析與操作改善

2026-09-23 · 範圍：src/ 前端 · 未進行 Git 寫入

重點：修正了幾個高頻痛點：版面設定不會保留、空編輯區沒有下一步、Command Palette 能執行的操作太少、複製時沒有回饋，以及鍵盤焦點看不到。自動化檢查全部通過（lint 沒有新增 warning），並已在真實 Chrome 中完成驗收。驗收時另外修正了兩個問題：空狀態按鈕太小、瀏覽器分頁名稱沒有翻譯。

已完成的改善

問題改善
重啟後 Sidebar／工具面板的寬度與收合狀態會重置AppShell 將版面存到 localStorage（yuzora:workbench-layout），讀取時會把數值限制在合法範圍。只記住使用者手動切換的狀態，窄視窗自動收合不會被存下。雙擊拖曳把手可還原預設寬度。
空編輯區只有說明文字，沒有可點的操作新增 EmptyEditorState，依「尚未開啟工作區」或「沒有分頁」顯示不同文案，並提供搜尋／指令、新 Terminal、瀏覽器三個按鈕，每個按鈕都標示快捷鍵。
Command Palette 標籤沒有翻譯、看不到快捷鍵、部分功能找不到模式項目改用翻譯後的標籤並顯示快捷鍵 kbd；新增切換 Sidebar、切換右側工具、SSH/SFTP 等項目。另新增 toggleTools 快捷鍵（Mod+Alt+B）。
複製路徑、hash、分支、位址時沒有任何回饋新增 lib/clipboardFeedback.ts：複製成功顯示 toast，失敗顯示錯誤。
TabBar 不支援中鍵關閉；螢幕閱讀器不會唸出「未儲存」；外部變更標記無法用鍵盤操作支援中鍵關閉；未儲存的分頁名稱會帶上「(unsaved)」／「（未儲存）」；外部變更標記改用真正的 <button>，並有 focus ring。
只在 hover 時出現的操作，用鍵盤聚焦時看不到FileTree、SFTP、HostList 的列操作按鈕在 focus-within／focus-visible 時也會顯示。
多個輸入框使用 outline-none，焦點只剩細微的框線變色GitSection、ProjectEditorPopover、GitNavContent、BranchPopover、LogsSection（2 處）、LogTab 補上 focus-visible／focus-within ring。
GUI 驗收發現：空狀態按鈕只有 22.75px 高、字級 10.4px（root font 為 13px，rem 尺寸會被縮小）改為 30px 高、12.5px 字級。
GUI 驗收發現：中文介面下，瀏覽器分頁仍顯示英文「Preview」TabBar 只在顯示時翻譯為「瀏覽器／Browser」（menus.tabBar.browserTabName），不改 store 用來比對分頁的名稱。
computer-use 實機發現：macOS 上 ⌘⌥B 沒有反應。Option 會把按鍵字元變成 ∫，原本的比對只 fallback 數字鍵（Digit*）dispatchAppShortcut 在 Alt 或 Shift 組合鍵時，也會 fallback 到字母鍵的實體按鍵 Key*，並新增回歸測試（套用舊邏輯時會失敗）。Playwright 模擬的按鍵事件不會產生 ∫，所以瀏覽器驗收時沒有抓到。
多處使用 transition-all全部改為明確列出的屬性（components/ui 之外已無殘留）。

新增的文案都已同時補齊 en 與 zh-TW。

設定頁重新設計

  • SettingCard 改為 shadcn Card 卡片；新增 SettingsRowGroup，將相關的開關列放進同一張卡片，列與列之間以細線分隔。外觀、編輯器、終端機、安全性、關於各頁都改用這兩種元件。
  • 頂列較精簡；搜尋框在尚未輸入時顯示 ⌘F／Ctrl F 提示，聚焦時顯示 accent 外框。
  • 側欄：分組標題改成小型大寫樣式；目前頁面左側有 accent 指示條，圖示也改用 accent 色；底部不再重複顯示「Yuzora Yuzora」，改為版本點加版本字串。
  • 頁首加上分區圖示；切換分頁時有淡入動畫（啟用 prefers-reduced-motion 時停用）；原本固定在底部的提示改放到內容末端。
  • 快捷鍵頁：每一列改成左側名稱加 Kbd、右側輸入框加套用按鈕；搜尋框加上圖示；「恢復預設」移到工具列。
  • 關於頁：版本旁顯示品牌圖示；更新狀態加上狀態點（未檢查／檢查中／可更新／錯誤），並新增「尚未檢查更新」文案（en／zh-TW）。
  • 主題卡 hover 時會微微上浮，選中時外框改為 accent 色；搜尋結果改成卡片清單。

Git Graph 日期欄

日期欄原本顯示相對時間（5m、3h、2d、May 24），現在統一顯示年月日 YYYY-MM-DD（本機時區）。滑鼠移到日期上會顯示含時分的完整時間。新增的 fullDate() 放在 src/lib/relativeTime.ts，fullDateTime() 也改為沿用它；資料庫查詢紀錄仍使用相對時間。
