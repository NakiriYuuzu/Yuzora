以開源技術打造

三個動作，跑起一個 agent 工作面

1

開一個 Space

選一個資料夾，在這台電腦或 SSH 連到的機器上都可以。Space 以資料夾命名，終端機從那裡開始。

2

派出 Agents

agent 跑在 herdr-core 的終端機；用「＋ 新增 pane」把 agent、終端機與工具放進同一個 tab。

3

盯著「需要注意」就好

agent 需要回覆時，側欄、tab 與 pane 邊框都會轉成琥珀色；處理完就回到主線。

整條開發動線，收進同一個工作面

資料庫，就在 agent 旁邊

PostgreSQL、SQL Server 與 SQLite：瀏覽 schema、看資料表與結構、執行 SQL，修改儲存格後在單一交易內寫回。

以 IntelliJ 為基準的 Git

在側欄暫存與 commit，diff 可以逐塊、逐行暫存；提交紀錄與分支圖、三方合併、互動式 rebase 都在同一個工作面。

細節也照顧到了

Command Palette

⇧⌘P 搜尋或執行命令，鍵盤不離手。往下打幾個字試試。

⇧⌘P

    檔案與編輯器

    帶 Git 標記的檔案樹、檔名與內容搜尋、tree-sitter 上色的編輯器，以及 Markdown 預覽。

    Mods 與模板

    Yuzora 的介面就是 herdr mods，複製後就能改；herdr-core 的 agent 模板在設定裡編輯、啟動。

    簽章更新

    新版本從 GitHub Releases 送達；更新清單的簽章與每個檔案的 SHA-256 都驗過才安裝。

    雙語介面

    繁體中文與英文，預設跟隨系統，在設定裡切換後整個 app 立即換上。這個網頁也是。
