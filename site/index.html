以開源技術打造

三個動作，跑起一個 agent 工作面

1

開一個 Space

掛上專案 checkout 或 linked worktree，Space rail 上一格就位。

2

命名 Session，派出 Agents

agents 直接跑在 HERDR terminal 上，同一個 Session 集中收納。

3

盯著 Attention 就好

需要介入的事自己浮上來，處理完就回到主線。

整條開發動線，收進同一個工作面

資料與主題，都在同一個工作面

瀏覽資料表、執行 SQL 並查看結果。示範介面使用範例資料，也能即時切換深淺模式與主題色。

終端機與 git 同步呼吸

在整合與並排 diff 之間切換，逐行檢視變更，再回到終端機查看專案狀態。
