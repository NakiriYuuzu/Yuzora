Oracle decision · Branches v2

名稱要能辨識，狀態要能判斷。

目前的 288px branch list 同時保留不可見的 Checkout 寬度，又用尾端截斷砍掉最關鍵的 leaf。Oracle 建議改成 340px Command-in-Popover，以 Local／Remote／Tags segments、prefix grouping 與狀態 badges 解決根因。

強適配：Command-in-Popover

保留高頻切換的空間錨定，不升級成沉重的管理 Dialog。搜尋只作用於當前分類，開啟即 focus。

分類＝Git Tags ＋ Status tags
Current目前 branch；不顯示 Checkout。
Goneupstream 已刪除，不再誤顯示為同步。
Local沒有 upstream，尚未發佈。
Git Tag第三個 refs segment，支援 detached checkout 與從 tag 建 branch。
Long names第一段 prefix 分組；row 顯示 leaf。搜尋時攤平完整名稱並高亮命中，title／aria 保留全名。
Geometry340px、max 92vw、最高 min(68vh, 520px)，side=bottom、collision padding 12px。
SegmentsLocal、Remote、Tags。沒有 Recent／Favorites，避免新增 persistence 與臆測功能。
Remote依 remote 分組；已有 local upstream 時標記 Tracked。Prototype 採明確「Checkout as local」。
Tags只提供 detached checkout、從 tag 建 branch、copy name；不加入 delete／push tag。
