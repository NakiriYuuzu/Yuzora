Yuzora · Git sidebar study

先選取，再操作。

目前的 +／− 把每列鎖成單檔操作，而列本身又立即開啟 DiffModal，導致已有的多選狀態完全不可見。本提案把側邊欄還原成一個真正的操作清單。

Primary surface · Operate
Oracle 建議：方案 B · Selection-first

單擊選取，雙擊／Enter 開 diff；hover 或 focus 顯示 checkbox。選取後在清單與 commit composer 之間固定顯示批次列。

互動架構
Branch context
兩行資訊塊：branch 名稱＋upstream／ahead／behind。Detached 明確標示，不偽裝成 branch。
Section scope
「未暫存」只暫存該節；「未追蹤」擁有自己的全選與全部暫存。
Multi-select
Checkbox toggle；Shift 依畫面順序 range；section checkbox 為 tri-state。
Bulk actions
混合選取可同時提供「暫存」與「取消暫存」；衝突列保留選取但排除 mutation。
Busy / stale
仍可選取與檢視；mutation controls disabled，沿用 repository-bound safety gate。

Click 選取 · ⇧ Click range · ⌘/Ctrl Click toggle · Enter diff · Space toggle · ⌘/Ctrl A 全選可見
